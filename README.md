CovidPackage is an R package that I created to visualize COVID-19 statistics for any selected country using an interactive Shiny web app. The package generates a series of
plots. And by integrating user input through a dropdown menu, the app dynamically updates all visualizations based on the country that was selected by the user. The data is sourced directly from Our 
World in Data.

Once you get the code going you can select a country from the dropdown menu, and the app will generate five plots: cases over time, deaths over time, vaccination rates, testing rates, and a combined 
overview.
